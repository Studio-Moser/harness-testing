# Visual acceptance

The automated check verifies layout, contrast, controls and focus. It does not judge taste.
Review the three rendered screenshots blindly for hierarchy, rhythm, balance and consistency.
Record remaining visual defects separately. Do not declare a design winner from CSS values or an automated pass alone.

Use solid-color backgrounds only. Gradients, background images, CSS filters/backdrop filters, masks, clipping paths and blend modes are outside this fixture's supported paint contract; typography, palette, spacing, borders and responsive layout remain your design choices.
