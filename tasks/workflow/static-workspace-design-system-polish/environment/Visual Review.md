# Multi-page visual acceptance

Review all four routes at phone, tablet and desktop sizes. Judge shared typography, palette, spacing rhythm, active navigation, table density, form clarity and consistency across page-specific patterns. Check that narrow layouts are intentional, not merely squeezed desktop layouts. Inspect control hierarchy and states. Do not reward a four-page scope implemented as four unrelated visual treatments. Automated acceptance verifies functional/layout minimums only; report remaining visual defects separately.

Use solid-color backgrounds only. Gradients, background images, CSS filters/backdrop filters, masks, clipping paths and blend modes are outside this fixture's supported paint contract; typography, palette, spacing, borders and responsive layout remain your design choices.
