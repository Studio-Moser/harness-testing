# Visual acceptance

Inspect all three card screenshots for readable hierarchy, balanced spacing and a clearly visible primary action. The requested change is bounded; do not reward unnecessary visual complexity. Automated geometry and contrast checks are not a taste judgment.

Use solid-color backgrounds only. Gradients, background images, CSS filters/backdrop filters, masks, clipping paths and blend modes are outside this fixture's supported paint contract; typography, palette, spacing, borders and responsive layout remain your design choices.
